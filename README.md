# ST Toolbox

一个按功能分目录组织的 SillyTavern 前端扩展，目前包含：

1. **QR 栏收起/展开**：在发送区加入切换按钮，并持久化收起状态。
2. **回复提示通知**：成功/错误提示音、自定义本地音频、标签页标题闪烁，以及生成事件去重。
3. **消息截图**：单条、相邻范围和任意多选截图，显式合成 SillyTavern 与 Moonlit Echoes 背景。
4. **对话导出**：按 char／user／全部及原始楼层筛选，探测并清理自选标签与思维链，导出 TXT、Markdown 或 JSONL。

## 安装位置

```text
SillyTavern/public/scripts/extensions/third-party/st-toolbox
```

重新加载 SillyTavern 后，设置页面位于：

```text
扩展设置 → 右侧栏（#extensions_settings2）→ ST Toolbox
```

ST Toolbox 内的每个功能都有独立折叠栏，展开状态会保存到 `extension_settings['st-toolbox'].ui.sections`，刷新后恢复；后续增加功能时不会让整个设置页面持续变长。

## QR 栏

- “启用 QR 栏切换按钮”打开时，切换按钮会出现在发送区扩展菜单按钮旁。
- 点击按钮，或在按钮聚焦时按 `Enter` / 空格，可收起和展开 Quick Reply 栏。
- 若 Quick Reply 栏尚未创建，插件会等待其出现；界面重绘后也会自动重新挂载。

## 提示通知

### 判定规则

- 只跟踪真正进入生成流程的可见回复。
- `dry-run`、`quiet`、`impersonate` 和被斜杠命令提前终止的生成不会提醒。
- 可见角色消息写入并完成渲染，且当前生成链不再继续：成功提醒。
- 流处理器明确失败，或生成进入空闲后持续没有有效角色消息：错误提醒。
- 点击停止按钮属于用户取消，不播放错误音。
- 自动续写、自动换页和函数工具递归按独立 generation leg 跟踪，只以生成链的最后结果提醒，避免中间步骤连续提示。
- 群聊按成员划分 generation leg，并只在整轮 `GROUP_WRAPPER_FINISHED` 后汇总提醒一次。

### 自定义音频

- 成功音和错误音可以分别选择、试听、上传和删除。
- 支持浏览器可播放的常见格式，包括 mp3、wav、ogg、m4a、aac、flac；单个文件上限 15 MB，最多保存 30 个。
- 上传内容只保存在当前浏览器的 IndexedDB，不上传到 SillyTavern 服务器；设置列表只常驻元数据，播放时才按 ID 读取 Blob。若另一浏览器缺少所选文件，设置页会保留选择并标为“本浏览器不可用”，不会反向清空服务器设置。
- 插件不会扫描或 HEAD 请求猜测的文件名，因此不会像候选文件扫描方案那样主动产生大量 404。

### 标签页闪烁

- 页面隐藏或窗口失焦时，标题会在基础标题和提醒标题之间切换；酒馆或其它扩展更新标题时，会记录新的基础标题并继续闪烁，不会因此停止图标切换。
- 浏览器仍可能对后台页面的计时器进行节流或冻结，插件无法保证后台闪烁始终保持固定频率。
- 页面重新可见或窗口重新获得焦点后立即停止；仅当当前标题/favicon 仍是插件写入的值时才恢复原值，避免覆盖其它扩展的修改。
- “闪烁时切换标签页图标”开启时，标签页图标会随标题一起交替：默认使用 vertin-tips 的两张图标（`features/notifications/icons/`，MIT，见其中的 NOTICE.md）；也可上传自定义图标，此时自定义图标与页面原 favicon 交替。
- 自定义图标会被缩放为 64×64 PNG（不超过 96 KB）直接存入设置，因此会随 SillyTavern 设置同步到其它浏览器；支持 png/jpg/gif/webp/svg/ico。

## 消息截图

### 使用方式

- 每条消息按钮区会出现相机按钮，单击截取当前消息。按钮接入 SillyTavern 原生消息模板，通过事件委托支持新消息及历史消息克隆；可在设置中选择常驻按钮栏或放进“…”展开菜单。
- 长按相机按钮 500 ms，可选择截取当前消息及前后 1–4 条消息。
- 在聊天选项菜单中点击“多选截图”，任选多条消息后，再次打开该菜单点击“生成多选截图”或“取消多选截图”。这些入口与“对话导出”均采用原生菜单项结构，跟随酒馆主题样式。
- 消息新增、用户消息、swipe、编辑、“加载更多”或聊天重绘后会自动补挂按钮；同一时间只执行一个截图任务。
- 一次截图只创建并复用一个消息渲染上下文，loading 只旋转相机图标；截图全程守护 `#chat` 与页面滚动位置，非用户触发的偏移会被自动复位。vendored 的 modern-screenshot 已修补为不向页面样式表写入 `@import` 字体规则，截图不会再引起页面重排。
- 截图前会先强制加载目标消息内的懒加载图片（如 LittleWhiteBox 插图的 `loading="lazy"`）并等待其完成后再测量尺寸，避免图片高度未计入导致底部被裁掉；尚未生成的插图会提示数量。
- 性能：图片按“显示尺寸 × 倍率”缩放后再嵌入（PNG 输出时保持无损）；图片、背景底图、`@font-face` 字体在多次截图之间复用缓存；库内部媒体等待上限从 30 s 降为 10 s。
- 切换聊天后会先等待 SillyTavern 的滚动、字体和媒体布局稳定，再一次性补挂按钮；第一次点击会等待当前聊天稳定，不会被插件自身的按钮 mutation 取消。

### 输出设置

- 支持 1–3 倍缩放；倍率会同时放大输出宽度和高度，例如 2× 的总像素数约为 1× 的 4 倍。过长图片会自动降低倍率，超过浏览器安全 Canvas 尺寸时停止并提示。
- 支持 PNG、JPEG、WebP；图片质量只控制 JPEG/WebP 的压缩程度，数值越高细节越完整、文件越大，PNG 不受该设置影响。
- 背景模式包括：当前 SillyTavern 背景、主题纯色、透明背景。JPEG 不支持透明，选择透明模式时会自动铺主题底色。

### Moonlit Echoes 背景修复

Moonlit Echoes 将 `#chat` 设为透明，并把真实视觉背景拆分到 `body`、负层级 `#bg1` 和 `#sheld::before`。直接克隆 `.mes` 时这些祖先/兄弟层不会被截入，因此旧插件导出的 PNG/WebP 可能透明。

ST Toolbox 会为每次截图单独构建背景 Canvas：

1. 先铺经过 alpha 合成的 body 主题底色，保证基础像素不透明。
2. 在克隆中把负层级背景改为可绘制层；若 DOM 渲染失败，再按 `background-size/position/opacity/filter` 直接绘制背景图片。
3. 合成 `#sheld::before` 的半透明色和 backdrop blur，再叠加 `#chat` tint；复杂的消息内部 backdrop-filter 采用近似效果。
4. 最后绘制消息前景。背景图片读取失败时仍保留不透明主题底色，不会重新变成透明图。

处理过程不会修改真实 `#bg1/#sheld/#chat` 的 inline style，也不会像参考插件那样临时隐藏聊天区域。

## 对话导出

### 使用方式

1. 在 **聊天选项菜单 → 对话导出** 或 **ST Toolbox → 对话导出 → 导出当前对话** 打开窗口。
2. 选择导出对象：全部、仅角色（char）或仅用户（user）。群聊中的所有角色都属于 char；系统消息默认排除，可在“全部”模式下勾选包含。
3. 选择楼层：留空或 `*` 导出全部，也可填写 `0-10,15,20-30`。楼层是 SillyTavern 的 **0 起始原始消息编号**，不是当前页面可见行的序号。范围包含两端；重叠自动合并，按聊天原顺序输出；倒序、越界和无效格式会报错，不会静默导出错误范围。先选楼层再筛选对象。
4. 按需勾选“移除思维链”，并点击 **探测所选楼层的标签**。候选显示标签名及成对／自闭合次数；勾选后自动填入移除列表，也可直接输入 `status, StatusBlock, 状态栏`。候选只扫描选中范围和对象。
5. 点击 **导出文件**。对象、格式、系统消息选项、思维链选项和标签列表会在成功探测／导出后保存；楼层范围不保存，避免切换聊天后误用旧范围。可取消任务，关闭窗口也会取消；聊天切换后需重新打开窗口，编辑、swipe 或开始生成会使当前任务失效。

### 清理和输出规则

- 默认开启移除思维链：去掉独立的 `extra.reasoning`，以及正文中的 `think`、`thinking`、`reasoning`、`analysis` 标签和内容；当前 ST 思维链模板若使用简单的成对标签，也会纳入。非标签格式的自定义分隔符（例如 `[思考]…[/思考]`）不自动识别。
- 关闭思维链移除时，独立思维链也纳入标签探测及清理，并在 TXT／Markdown 中单列；JSONL 保留清理后的 `extra.reasoning`。
- 自选标签不区分大小写，支持中文名、属性、跨行、同名嵌套和自闭合标签。只移除明确选中的标签及包裹内容，未选中的文本／格式原样保留。**代码块内的真实标签也会处理**；`&lt;status&gt;` 等已转义文本不处理。HTML 注释不会成为标签候选。
- 未闭合标签不作为成对标签候选；手动选中后会保守删除至该条消息末尾，导出结果提示数量，避免泄漏待清理内容。普通 HTML 排版标签只提供候选，不自动勾选。
- 读取 `getContext().chat` 原始数据，未加载到页面的楼层也可导出；每楼仅导出当前 `mes`（当前 swipe），不导出历史回复。清理后为空的消息仍保留。
- TXT／Markdown 标注原始楼层和发言者。JSONL 使用 SillyTavern 可识别的头行与消息结构，原始楼层记录在 `extra.st_toolbox_original_floor`；导入后 ST 界面仍按导入的消息顺序重新编号。
- JSONL 是**精简的当前回复导出**，不是完整备份：不携带 swipes、swipe_info、附件二进制／媒体元数据、工具调用、思维链签名和任意扩展／聊天元数据，避免在隐藏字段中重新带出被清理内容。正文自身已有的链接或图片标记会按原文保留。
- 全部处理在本地浏览器完成，不上传聊天，不更改原始消息；下载内容不是渲染后的网页或截图。

### 性能与安全限制

- 不在聊天流式生成时扫描，不为每楼添加按钮，不挂载 MutationObserver；后台事件只做任务失效标记。解析模块在首次打开导出窗口时加载。
- 优先使用一次性模块 Web Worker；任务结束／取消后销毁，导出 Blob 在 Worker 内构建，避免大结果文本重复回传。Worker 不可用时自动降级到分批让出主线程的处理，单条超长消息也会分段让出。
- 快照只复制符合条件的当前文本字段，不深拷贝聊天或 swipe；角色／楼层不匹配的正文不会传给 Worker。不对每个标签重复全量正则替换。
- 标签候选最多显示 200 种，手动移除最多 128 个标签，解析栈最多 4096 个未闭合标签；所选源文本限制约 64M 字符，聊天最多 20 万楼，超限需缩小范围或拆分聊天。时间字段异常超过 256 字符时会拒绝导出该楼，避免异常元数据触发巨量复制。超大文件的浏览器 Blob 分配仍可能产生短暂延迟，建议分段导出。
- 聊天标题、发言者、候选标签均不作为 HTML 执行，文件名会清理非法字符。下载 Object URL 会在 60 秒后或页面离开时释放。

### 验证

在 `st-toolbox` 目录运行（Node.js 20+）：

```sh
node --test tests/chat-export.test.mjs tests/chat-export-integration.test.mjs tests/chat-export-ui.test.mjs
node tests/chat-export-benchmark.mjs
```

测试包括纯数据处理、真实 Node Worker 线程集成和使用轻量 DOM／Popup 替身的界面生命周期验证；不等同于浏览器端到端测试。基准耗时取决于机器和运行环境。

浏览器手动检查建议：单聊／群聊与未加载的历史楼层；切换角色及楼层范围；中文／嵌套／未闭合标签；思维链开关；三个格式下载和 JSONL 重新导入；取消、关闭、切换聊天和流式生成；手机窄屏和 Worker 被禁用时的降级。

## 注意事项

- 请停用 `SillyTavern-SimpleQRBarToggle`、`vertin-tips` 和 `html2canvas-pro` 中对应的旧功能，否则可能出现重复 QR 按钮、提示音或截图按钮。
- 如果 SillyTavern 自带的 **Message Sound** 仍处于启用状态，它会与本插件的自定义成功音各播放一次；只需要一套声音时请关闭其中一项。
- 浏览器可能在用户首次与页面交互前阻止自动播放；通常发送第一条消息后即可正常播放，也可先在设置页点击试听。
- 两个内置提示音来自本地 `vertin-tips` 参考扩展中实际存在的音频，并复制到本扩展自己的固定资源路径；运行时不会依赖参考扩展。
